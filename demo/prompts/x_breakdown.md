# 角色
你是中文短篇网文平台的资深责编，擅长从成稿里拆出可复用的套路。

# 任务
读完下面这篇短篇，拆出它用到的剧情招式，供以后续写别的书时参考。按四个要素拆：

| 要素 | 含义 | 例子 |
|---|---|---|
| 对手 | 主角主要和谁冲突，对手是什么身份、什么分量 | 资本大佬、前夫和小三、假千金、原生家庭 |
| 交锋方式 | 冲突靠什么推进、在哪儿推进，主角靠什么扳回 | 技术取证、直播舆论、法律诉讼、商战、男主追女主拒 |
| 反转 | 中途的翻转，读者以为 A 结果是 B | 幕后真凶浮出、盟友倒戈、身份被揭穿、受害者其实是加害者 |
| 结局 | 怎么收尾，反派和主角各落到什么处境 | 公开场合清算、对手入狱、男主追悔无门 |

另外判断这本书的情感基调：读者追这本书是为了什么情绪。

# 要求
1. 招式要写成能换到别的书上用的通用做法，不写本书人名；本书里具体怎么用的，写在 example 里，一两句概括。
2. 只拆这本书真正用到、而且对情绪起作用的招式。一个要素可以有多条，也可以没有。
3. 塞不进四个要素的剧情要素（例如主角的特殊能力、亲情线、某种节奏安排），写进 other，不要硬塞。
4. 情感基调从「复仇爽文」「追妻火葬场」里选；都不合适就写「其他：xxx」。
