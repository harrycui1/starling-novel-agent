# 讨论记录：切点与续写方向策略

日期：2026-10-28

**一句话结论：切点不是一个独立决策，而是「方向」节点的产出。方向节点先由模型读懂原文（类型契约、高光、门关上、剩余势能），再给出三条续写路线，每条路线自带切点和高光账本；编辑只负责选路线，调优在线下做。**

上一份记录（2026-10-27，含编辑评分，未入公开仓库）的结论是：问题不在文笔，而在动笔前的三件事——从哪里切、守住什么类型、后两万字靠什么冲突撑。本次讨论把其中「从哪里切」和「靠什么冲突」落成了可执行的策略。

## 讨论脉络

| 阶段 | 做了什么 | 得到的认知 |
|---|---|---|
| 代码层方案 | 先按切点、类型契约、章长三项列了代码改动 | 产品侧更需要先定策略，不需要讨论代码细节 |
| 原高潮怎么处理 | 原作 1 万字里高潮在 75%～80% 处，成品 3 万字后只在 25%～30% 处 | 原高潮必然变成新故事前段的节点；先定怎么处理原高潮，切点是结果 |
| 三种处理方式 | 延后、保留再造第二高潮、拆开逐步兑现 | 延后会压低爽点频率，少用；后两种都可以，保留原高潮天然能增加反转 |
| 读 8 本测试小说 | 逐本诊断类型、后 20% 内容、剩余势能 | 后 20% 并不都是爽点；8 本都有可用势能 |
| 抽象成策略 | 类型识别 → 高光盘点 → 势能盘点 → 切点决策 | 核心矛盾是空间和保真的取舍 |
| 明确分工 | 原文理解由模型直出，编辑只选方向 | 编辑反馈来自选择和否决理由，不让编辑做标注 |
| 产出 | 8 本书的原文理解和方向文档（给编辑看）、提示词草案 | 见文末 |

## 核心矛盾

切点本质上是一个取舍：

- 切得早：续写空间大，但删掉的原作高光多，每个都要补回来，补不好就是降级。
- 切得晚：原作高光都保住，但门快关上了，新冲突只能硬造，两万字撑不住。

所以「从哪里续写」和「续写后会不会更爽」是同一个问题：找到一个切点，让删掉的高光都能补回来，剩下的空间有足够的势能填满。

「更爽或至少不降级」用两条标准检查：

1. 不丢：被删的每个高光（爽点、情感、反转）在新稿里都有对应的位置，强度不低于原作，可以挪位置。
2. 新高：续写的终局高光至少与原作最强高光持平，目标是超过。

标准看强度，不看数量。靠堆爽点数量显得「更爽」，结果是密集又同质的水文。

## 跨书的五个发现

1. 后 20% 有四种内容：爽点兑现、情感高光、反转揭秘、已经是第二冲突。只保护爽点，会丢掉 01 的奶奶那场戏和 04 的「将计就计」，而它们是全书最好的段落。
2. 原作在结尾一笔带过的部分，正是续写最该展开的部分（03 第 7 章、04 第 14 章、05 第 9 章）。
3. 剩余势能有固定来源，可以做成诊断清单：漏网反派、未兑现狠话、埋了没用的设定（含未解谜团）、未展开人物、主角软肋。
4. 「爽」在不同类型里含义不同：02 是追悔加女主过得更好，08 是被宠被独占。类型契约要按书写。
5. 主角太强时（04、06、01），第二冲突要打在软肋上：主角的秘密、在乎的人、自设的约束。

## 方向节点的策略

### 原文理解（模型直出，编辑只看不改）

1. 类型契约：这本书的「爽」指什么、读者期待什么、禁止哪些走向。
2. 高光清单：位置、类型（爽点、情感、反转）、强度。
3. 门关上：故事宣告尘埃落定的位置。
4. 剩余势能：按五类清单找，每条附原文依据。

### 方向生成（三层）

1. 可行性：切点在门关上之前；不跑出类型契约；不丢；新高；第二冲突来自某条势能，不凭空编造。
2. 差异性：三个方向固定走三条路线，而不是换三个套路。
3. 可检查：每个方向附切点、高光账本、所用势能、终局高光。

三条路线：

| 路线 | 做法 |
|---|---|
| 路线一（稳妥） | 保留原作高潮，在大结局之前切开，接一段新冲突 |
| 路线二（深挖） | 在原作高潮之前切开，把它拆成几步慢慢兑现，最终清算放到最后 |
| 路线三（换路） | 和路线一切在同一处，新冲突换一条势能 |

某条路线在这本书上不成立时（例如 07 原作高潮在一半处，深挖会删掉半本书），少给一个方向并写明原因，不硬凑。

### 编辑的角色

编辑只做两件事：选一条路线；或者否决，并从固定理由里选一个（类型跑偏、切点不对、新冲突生硬、不够爽、高光降级、原文理解有误）。这些数据用来定位策略哪一层出了问题，调优（改 prompt 或规则、在固定样本上重跑）由产品和工程在线下完成。

## 修正的旧结论

| 旧结论（2026-10-27） | 新结论 |
|---|---|
| 切点落在冲突最高点之前 | 切点落在「门关上」之前；高潮之后、收尾之前切开同样成立 |
| 被删的原作爽点只能加码，不能降级 | 被删的原作高光（爽点、情感、反转）只能保留或加码，可以挪位置 |
| 切点在理解原文时给出，整本书一个，编辑确认 | 切点属于每个方向，不同方向可以切在不同位置；评测时人为固定切点 |
| 三个方向的主套路两两不同 | 三个方向固定走三条路线，差异在切点、势能、高光处理方式 |
| 切点不早于约 75% 处 | 下限改为保留原文不少于 60%（草案默认值，待定）；按原作结构决定，不按百分比 |
