# 跨电脑接力

## 使用哪个分支

当前精简流程在 `codex/full-text-workflow`，功能实现提交为 `2dbb083`。其他分支可能仍是逐章档案和阻断审核的旧流程，接手时先确认当前分支。

首次克隆：

```bash
git clone -b codex/full-text-workflow https://github.com/harrycui1/starling-novel-agent.git
cd starling-novel-agent
```

已有仓库：

```bash
git fetch origin
git switch codex/full-text-workflow
git pull --ff-only
```

如果本地还没有这个分支，使用 `git switch --track origin/codex/full-text-workflow`。

## 配置和启动

需要 Python 3.11+、uv 和 Node.js。依赖不需要从旧电脑复制。

1. 复制 `.env.example` 为 `.env`，在新电脑配置模型连接和密钥；如从旧电脑迁移 `.env`，通过自己信任的私密方式单独传输，不提交到仓库。
2. 只接代码可直接启动。继续现有稿件时，将本地接力包中的 `data/` 恢复到仓库的 `data/`；若新电脑已有自己的数据，先另存，不覆盖。
3. 运行 `./start.sh`，打开 `http://127.0.0.1:8767`。启动会安装依赖、构建前端并应用数据库迁移。

接力包只包含本机数据和校验清单，不含 `.env`、密钥、依赖或代码。运行中的SQLite数据库通过备份接口导出，不能只复制数据库主文件而漏掉WAL内容。包内可能含原文和稿件，不要上传到代码仓库。
